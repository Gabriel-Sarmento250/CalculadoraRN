# 🧮 Calculadora RN

Aplicativo de calculadora mobile desenvolvido em **React Native + TypeScript** como projeto de estudo de desenvolvimento mobile.

## ✨ Funcionalidades

- ➕ Operações básicas: soma, subtração, multiplicação e divisão
- 🧹 Botão de limpar (C)
- ⌫ Botão de apagar último dígito
- 📱 Interface responsiva para Android e iOS
- 🎨 Design simples e intuitivo

## 🛠️ Tecnologias

- **React Native** — framework mobile
- **TypeScript** — tipagem estática
- **Expo** — ambiente de desenvolvimento
- **React Hooks** — gerenciamento de estado

## ⚙️ Como rodar o projeto

### Pré-requisitos
- Node.js instalado
- Expo Go no celular (ou emulador Android/iOS)

### Passo a passo

\`\`\`bash
# Clone o repositório
git clone https://github.com/Gabriel-Sarmento250/CalculadoraRN.git

# Entre na pasta
cd CalculadoraRN

# Instale as dependências
npm install

# Inicie o projeto
npx expo start
\`\`\`

Depois é só escanear o QR Code com o app **Expo Go** no celular. 📱
